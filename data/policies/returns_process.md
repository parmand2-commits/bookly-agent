# How to return an item

Once an order is confirmed eligible (see returns_window), the customer packs the book in its original or equivalent packaging and ships it back using the prepaid label generated when the return is created.

Return postage is **charged to the customer** unless the return is caused by a Bookly error, such as a damaged or incorrect item — those cases are not processed through this flow (see damaged_or_wrong_item).

Every return is assigned an **RMA number in the format RMA-######** (six digits) at the moment the return is created. The customer must write this number on the outside of the parcel; parcels without a visible RMA number can be delayed or refused at the depot.

Support agents create the return in the order system only after the customer has explicitly confirmed the item and reason. Do not generate a label before that confirmation.

For the return window itself, see returns_window. For when the refund lands, see refund_timing.

## Escalate if
- The customer says the parcel was lost after drop-off
- The customer disputes being charged for return postage
- The item is damaged or incorrect (see damaged_or_wrong_item)
- No RMA number was generated but the customer claims to have returned the item
