# Resetting a password

Customers reset their own password from the login page by requesting a reset link sent to the email on file. The link is **valid for 60 minutes** from the moment it is sent; after that it expires and a new one must be requested.

Support agents cannot reset a password manually or view a customer's existing password. If a customer says they never received the email, confirm the email address on the account first, then ask them to check spam or request a new link — do not resend the same link, since a new request generates a new one and invalidates the previous one.

Repeated reset requests in a short period may trigger a temporary lock on the reset function itself, separate from the account.

For requests to close the account entirely or access stored data, see account_and_privacy.

## Escalate if
- The customer no longer has access to the email address on file
- Reset links repeatedly fail to arrive after confirming the correct address
- The account appears locked outside of the normal reset flow
- The customer suspects unauthorized access to the account
