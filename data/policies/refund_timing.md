# Refund timing and method

Refunds are issued **5 to 10 business days after the returned item is received and inspected** at the warehouse, not from the day the customer ships it. The countdown does not start at drop-off or at RMA creation (see returns_process).

The refund is always issued to the original payment method used at checkout. Bookly does not refund to a different card, bank account, or as store credit, unless the original method is no longer valid — in that case, loop in the finance team.

If the stated window has elapsed and no refund has appeared, check the order system for the inspection date before responding. Do not assume the return was received just because it was shipped.

For return eligibility, see returns_window. For the return process itself, see returns_process.

## Escalate if
- The window in this file has elapsed since the inspection date with no refund issued
- The original payment method is closed, expired, or no longer valid
- The customer disputes the inspection outcome
- The return is marked received but has no inspection date logged
