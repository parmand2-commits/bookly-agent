# Cancelling an order

An order can be cancelled **only while its status is not yet "shipped"** in the order system. Once an order moves to shipped, it cannot be cancelled; the customer must wait for delivery and use the standard return process instead (see returns_window and returns_process).

Support agents must check the live order status before promising a cancellation — a status of "processing" or "preparing" is still cancellable, but this can change at any time, including while the agent is on the call or chat with the customer.

Pre-order cancellation follows the same status rule; because pre-orders are not charged until they ship (see preorders), a cancelled pre-order that has not yet shipped is not charged at all.

Cancelling an order does not require a reason from the customer.

## Escalate if
- The order status changes to shipped while the cancellation is being processed
- The customer insists the order should still be cancellable despite a shipped status
- The cancellation request concerns a delayed order (see delayed_orders)
- The system will not allow cancellation for an order still showing as unshipped
