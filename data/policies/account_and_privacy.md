# Account data requests

Customers can request a copy of the personal data Bookly holds on them, or request its deletion, including closing the account entirely. Bookly must respond to an access or deletion request **within 30 days** of the request being logged.

Support agents log the request in the privacy system with the customer's verified identity and the type of request (access, deletion, or both); agents do not compile or send the data themselves. Verification must use the email or account details on file — do not accept a verbal claim of identity alone.

Deleting an account does not cancel an order already in progress or reverse a return or refund already completed; those follow their own policies independently of the account closure.

For login issues short of a data request, see password_reset.

## Escalate if
- The customer's identity cannot be verified through account details on file
- The request combines deletion with an open order or an active return
- The 30-day response window has elapsed without a reply
- The request comes from someone other than the account holder
